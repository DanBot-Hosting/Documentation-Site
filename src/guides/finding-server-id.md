# How to Find My Server ID?

Your Server ID is a unique identifier used to manage your server. This guide explains two ways to find it.

## Method 1: Use Discord

1. Go to the [#⌛╏commands](https://discord.com/channels/639477525927690240/898041850890440725) channel in the DanBot Hosting Discord server.
2. Type the following command:

   `DBH!server list`

3. Find your server in the list and copy its Server ID.

## Method 2: Use the Web Panel

1. Open the [DBH Panel](https://panel.danbot.host/) and go to your server.
2. Look at the Pterodactyl URL in your browser's address bar.
3. Copy the value after `/server/`. For example, in:

   `https://panel.danbot.host/server/6bd84f61`

   your Server ID is `6bd84f61`.
